YASH GYM TRACKER — ANDROID SETUP

This is an offline-capable web app. It includes original local exercise illustrations, daily workout checklists, weight/notes fields, rest timer, weekly overview, and JSON export.

IMPORTANT: Browser storage is device/browser-specific. Do not clear browser data unless you exported a backup.

EASIEST WAY:
1. Extract this ZIP.
2. Upload the extracted folder to a static web host that supports HTTPS (for example GitHub Pages or Netlify).
3. Open the HTTPS site in Chrome on Android.
4. Chrome menu ⋮ > Install app / Add to Home screen.
5. After the first successful load, it can work offline through its service worker.

LOCAL TEST:
Opening index.html directly shows the app, but install/offline service-worker features generally require HTTPS or localhost.

The included SVG illustrations are simple original exercise diagrams, not real gym photographs.
